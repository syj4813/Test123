# 코레일 이용 환경 편익 계산 프로그램

출발지·도착지·탑승 인원수를 입력하면 **자차 / 고속버스 / 철도** 3가지
수단의 탄소(CO2eq)·미세먼지(PM2.5eq) 배출량을 계산하고, 철도 이용 시
편익(절감량)을 산출합니다.

## 1. 설치

```bash
pip install requests streamlit
```

## 2. API 키 준비 (필수, 두 개)

| 용도 | 서비스 | 이유 |
|---|---|---|
| 지오코딩 (주소→좌표) | Google Geocoding API | 정상 작동 |
| 도로거리 (자동차/터미널/역 접근) | 카카오모빌리티 길찾기 API | **Google Directions는 한국 내 도로 경로를 지원하지 않음** (국내 지리정보 국외반출 제한으로 인한 정책적 제약) |

**Google**: Google Cloud Console에서 Geocoding API 활성화 후 키 발급.
**카카오**: https://developers.kakao.com → 애플리케이션 추가 → REST API 키 발급.

**방법 A (환경변수, 권장):**
```bash
export GOOGLE_MAPS_API_KEY="발급받은 구글 키"
export KAKAO_REST_API_KEY="발급받은 카카오 키"
```
(Windows 명령 프롬프트는 `set 변수명=값`, PowerShell은 `$env:변수명="값"`)

**방법 B (코드에 직접 기록):**
`config.py`를 열어 아래 두 값에 키를 채워 넣으면, 환경변수를 매번 설정할
필요 없이 바로 실행됩니다.
```python
DEFAULT_GOOGLE_MAPS_API_KEY = "발급받은 구글 키"
DEFAULT_KAKAO_REST_API_KEY = "발급받은 카카오 키"
```
환경변수가 있으면 그게 우선이고, 없을 때만 이 값을 씁니다. **팀 배포용
exe에 키를 심고 싶다면 이 방법을 쓰면 됩니다** (자세한 주의사항은 9절 참고).

## 3. 실행

### 3-1. 콘솔(터미널)에서

```bash
python main.py
```

```
탑승 인원수 (숫자만, 예: 1): 3
출발지 (정확한 주소나 장소명, 예: '서울시 강남구 테헤란로 152'): 서울시 강남구 테헤란로 152
도착지 (정확한 주소나 장소명, 예: '부산 해운대 시그니엘'): 부산 해운대 시그니엘
```

### 3-2. 웹사이트로 (팀원과 링크로 공유하고 싶을 때)

```bash
streamlit run app.py
```

브라우저가 자동으로 열리고 `http://localhost:8501`에서 폼(인원수/출발지/
도착지)을 입력하면 결과가 카드 형태로 표시됩니다.

**팀원들과 같은 사내망에서 공유하려면:**

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

이후 이 컴퓨터의 사내망 IP를 팀원에게 알려주면(`http://<이 컴퓨터 IP>:8501`)
각자 브라우저로 접속해서 씁니다. 컴퓨터를 끄면 접속이 끊기니, 계속 켜두고
쓸 서버가 있다면 그쪽에 올려두는 게 좋습니다. (`nohup streamlit run app.py
--server.address 0.0.0.0 &` 로 터미널을 닫아도 계속 돌게 할 수 있습니다.)

## 4. 핵심 설계 원리

| 수단 | 이동 구간 | 거리 산출 방법 |
|---|---|---|
| 자차 | 출발지 → 도착지 | 카카오 길찾기 API 실제 도로거리 |
| 고속버스 | 출발지→출발터미널(자차) → 출발터미널→도착터미널(버스) → 도착터미널→도착지(자차) | 터미널 선정: 좌표DB 후보 3곳 → 카카오 API로 실거리 계산 후 최솟값 선택 |
| 철도 | 출발지→출발역(자차) → 출발역→도착역(철도) → 도착역→도착지(자차) | 역 선정은 버스와 동일 방식. **역간 철도거리는 도로 API로 계산 불가** → 코레일 공식 데이터 그래프 사용 |

**철도는 KTX/무궁화호/새마을호 세 등급을 모두 계산해서 같이 보여줍니다.**
출발역·도착역 선정과 역간 실제거리는 등급과 무관하게 동일한 물리적 경로를
쓰고(같은 선로를 다른 등급의 열차가 다닌다고 가정), 등급별 배출계수만
다르게 적용합니다. 즉 "이 구간에 그 등급 열차가 실제로 다니는지"는 확인하지
않는 단순화된 비교용 수치입니다 (예: 무궁화호는 배출계수 자체가 고속버스보다
높아서, 계산상 무궁화호가 고속버스보다 배출량이 더 많게 나올 수도 있습니다 -
이건 버그가 아니라 원본 배출계수 데이터상 사실입니다).

역간 철도거리를 도로 API로 계산하지 않는 이유: 철도는 선로를 따라가므로
도로 네트워크와 경로가 전혀 다릅니다.

**철도 역간거리는 근사치가 아니라 한국철도공사 공식 데이터
(`한국철도공사_철도운행거리_전체_20240901.xlsx`)를 파싱한
`data/rail_edges.csv`(인접역 간 실제 선로거리 671개 구간, 638개 역)를
그래프로 구성해 다익스트라 최단경로로 계산합니다.** 서로 다른 노선(예:
경부선의 서울과 경강선의 강릉)에 있는 두 역도 오송·동대구·청량리 같은
접속역을 거치는 최단경로로 자동 연결됩니다. 그래프에 없는 역(아주 작은
간이역 등)일 때만 직선거리×1.15 근사를 쓰고, 그 경우에만 결과에 `⚠`
경고가 표시됩니다.

> 수도권 광역전철 전용 구간(과천·분당·일산선, 수인선, 서해선)은
> 그래프에서 제외했습니다. KTX/무궁화/새마을 중장거리 비교에 기여가
> 없고, 지방 노선과 동일한 역명(예: 분당선 '구룡' vs 경전선의 동명 역)이
> 있어 그래프를 잘못 이어버릴 위험이 있었기 때문입니다.

## 5. 탑승 인원수는 배출량에 이렇게 반영됩니다

- **자동차**: 배출계수가 '5인승 승용차 1대' 기준입니다. 1~5명은 필요한
  차량이 1대뿐이므로 배출량이 동일하고, 6명부터는 `ceil(인원수/5)`대의
  차량이 필요하다고 보고 그만큼 배출량이 늘어납니다 (6명→2대, 11명→3대).
- **고속버스/열차**: 배출계수가 '좌석 1인당' 기준이라 인원수에 정비례합니다.
- **역/터미널 접근용 자차 구간**: 일행이 함께 차로 이동한다고 가정해
  자동차와 동일한 규칙(5인당 1대)을 적용합니다.

## 6. 정확도를 높이려면 (선택)

### 6-1. 철도 역간 실제거리 데이터 갱신/보강
`data/rail_edges.csv`는 (역A,역B,km) 인접역 거리 목록입니다. 코레일이
새 노선을 개통하거나 데이터를 갱신하면 같은 형식으로 행을 추가/수정하면
됩니다. `parse_rail_distance.py`를 다시 돌리면 원본 엑셀이 갱신되어도
자동으로 반영됩니다.

### 6-2. 역/터미널 DB 확장
지금 내장된 DB는 주요 역·터미널 위주의 스타터 셋입니다.
`data/stations.csv`, `data/terminals.csv` 를 만들면 자동으로 우선 로드됩니다
(형식은 `stations.py`, `terminals.py` 상단 주석 참고).

## 6-1. 이동 경로도 함께 표시됩니다

각 구간마다 실제 경로 정보가 붙습니다.

- **자차/버스/역·터미널 접근 구간**: 카카오 길찾기 API가 알려주는 주요
  도로명을 순서대로 보여줍니다 (예: `테헤란로 → 경부고속도로 → ...`).
  아주 짧은 이면도로는 생략합니다.
- **철도 구간**: 코레일 데이터 그래프상 실제 경유하는 역 목록을 보여줍니다
  (예: `서울 → 수원 → ... → 부산`). **주의**: 이건 '선로상 경로'일 뿐이고
  KTX가 그 역들에 전부 정차한다는 뜻은 아닙니다. 완행 구간까지 포함된
  경로라 정차역보다 훨씬 많은 역이 나열될 수 있습니다.

웹 UI(`app.py`)에서는 고속버스/철도 카드 아래 **"전체 경로 보기"**를 눌러야
출발지→터미널(또는 역), 터미널(또는 역)→도착지 접근 구간의 도로명까지
전부 펼쳐 볼 수 있습니다. 카드에는 공간상 핵심 구간(버스/열차 구간)만
기본으로 보입니다.

## 8. 알려진 한계

- "집", "회사"처럼 개인화된 표현은 Geocoding API가 이해하지 못합니다.
  실제 주소나 구체적 장소명을 입력해야 합니다.
- 버스는 터미널 간 도로거리로 근사합니다. 실제 고속버스 노선이 경유지를
  거치며 우회하는 경우 오차가 발생할 수 있습니다.
- 열차 등급(KTX/무궁화/새마을)은 세 개를 모두 계산해서 보여주지만,
  실제로 그 등급 열차가 그 구간에 다니는지는 확인하지 않습니다.
- 철도 역간거리는 코레일 공식 데이터의 최단경로(다익스트라) 값입니다.
  실제로 그 경로에 KTX/무궁화/새마을 직통 서비스가 있는지는 확인하지
  않으므로(환승이 필요한 경우 실제 이용거리·시간과 다를 수 있음),
  큰 틀의 배출량 비교용으로 쓰는 것을 권장합니다.
- 수도권 광역전철 전용역(과천·분당·일산선, 수인선, 서해선 소속 역)은
  거리 그래프에서 제외되어 있어, 이 구간에 속한 역이 최근접 역으로
  선택되면 근사치(⚠ 표시)로 대체됩니다.
- 인원수가 6명을 넘으면 자동차/접근구간 배출량이 계단식으로(5명 단위)
  증가합니다. 실제로는 몇 명이든 차 1대에 낑겨 탈 수도 있지만, 배출계수
  자체가 "5인승 승용차 1대" 기준이라 이 이상은 물리적으로 불가능하다고
  보고 차량 대수를 늘리는 쪽으로 처리했습니다.
- 고속버스는 좌석 정원(약 40~45석) 제한을 걸지 않았습니다. 극단적으로
  많은 인원(수십 명)을 입력하면 실제로는 버스를 여러 대 나눠 타야 하는
  상황도 현재는 1대분 요금으로 단순 정비례 계산됩니다.

## 9. exe로 만들어 팀에 배포하기

> 참고: 팀원들이 다 사내망/같은 와이파이에 있다면, 위 3-2절의
> **웹 UI를 서버 하나에 띄워두고 링크만 공유하는 게 더 간단**합니다.
> exe는 "서버 없이 각자 컴퓨터에서 독립 실행"이 필요할 때만 고려하세요.

**exe는 `main.py`(콘솔 버전) 기준으로 만드세요.** `app.py`(웹 UI/Streamlit)는
exe 패키징이 까다롭고(정적 파일 별도 포함 필요, 결국 로컬 서버+브라우저
방식이라 "독립 실행 프로그램" 느낌도 덜함) 실익이 적습니다. 콘솔 버전은
exe로 만들면 **받는 사람 PC에 Python/Anaconda가 전혀 없어도 실행됩니다**
(exe 안에 파이썬 실행환경이 통째로 들어가기 때문).

```bash
pip install pyinstaller
pyinstaller --onefile --add-data "data;data" main.py
```

- `dist/main.exe`가 생성됩니다. **`config.py`에 키를 채워뒀다면 이 exe
  하나만 팀원에게 주면 바로 실행됩니다** (팀원 PC에 API 키 설정이 필요
  없음).
- `--add-data "data;data"` 옵션이 꼭 필요합니다. 안 넣으면 exe가
  `data/rail_edges.csv`를 못 찾아서 역간거리 계산이 근사치로만 돌아갑니다.
  (Mac/Linux에서 만들 때는 세미콜론이 아니라 콜론: `--add-data "data:data"`)

**배포 전 꼭 확인할 것 (보안/비용 관련):**

1. **키가 노출된다는 걸 전제로 하세요.** exe 안에 키를 심어도 `strings
   dist/main.exe` 같은 명령 한 줄로 키가 그대로 보입니다. "암호화"나
   "숨김" 처리가 안 됩니다. 팀 내부용이라 이 정도 리스크는 감수한다는
   전제로 진행하는 게 맞고, 외부에 뿌릴 프로그램이면 이 방식을 쓰면
   안 됩니다.
2. **키에 반드시 제한을 걸어두세요.** Google Cloud Console / 카카오
   디벨로퍼스에서 일일 호출 한도를 낮게 설정하세요. 키가 새어나가도
   피해가 그 한도 내로 제한됩니다.
3. **문제가 생기면 즉시 키를 재발급(rotate)하세요.**
4. **콘솔 창이 뜹니다.** 지금 `main.py`는 `input()`으로 물어보는 콘솔
   프로그램이라 exe로 만들어도 검은 콘솔창이 뜹니다. 더블클릭해서 쓰는
   진짜 "프로그램"처럼 보이려면 GUI를 씌워야 하는데, 이건 10절 내용과
   같은 방향이라 아래에서 다룹니다.
5. **바이러스 백신 오탐 가능성.** PyInstaller로 만든 exe는 서명이 없어서
   일부 백신/윈도우 Defender가 경고를 띄울 수 있습니다. 팀원들에게
   미리 "직접 만든 프로그램이라 그렇다"고 안내해두면 좋습니다.

## 10. 웹 UI(app.py)를 exe로 만들기 (더블클릭하면 브라우저가 자동으로 열림)

콘솔 대신 웹 화면이 뜨는 exe를 원하면 `run_web.py`(웹 UI 실행용 런처)를
씁니다. `main.py`보다 패키징이 까다롭고 exe 용량도 훨씬 큽니다(200MB+).

```bash
pip install pyinstaller

pyinstaller --onefile ^
  --add-data "app.py;." ^
  --add-data "calculator.py;." ^
  --add-data "road_distance.py;." ^
  --add-data "rail_distance.py;." ^
  --add-data "geocode.py;." ^
  --add-data "emission_factors.py;." ^
  --add-data "stations.py;." ^
  --add-data "terminals.py;." ^
  --add-data "config.py;." ^
  --add-data "data;data" ^
  --collect-all streamlit ^
  --collect-all altair ^
  --name korail_web ^
  run_web.py
```

`dist\korail_web.exe`를 더블클릭하면 로컬 서버가 뜨고 기본 브라우저가
자동으로 열리면서 계산기 화면이 나옵니다. 콘솔창은 서버가 돌아가는
창이므로 사용 중엔 닫으면 안 됩니다.

**흔한 문제:**

| 증상 | 해결 |
|---|---|
| 흰 화면만 뜸 | `--collect-all streamlit`이 빠졌거나 부족함. `--collect-all pyarrow --collect-all pandas` 추가 후 재빌드 |
| `ModuleNotFoundError` | 그 모듈명으로 `--hidden-import 모듈명` 추가 후 재빌드 |
| 브라우저가 안 열림 | 콘솔창에 뜨는 `Local URL: http://localhost:8501`을 수동으로 브라우저 주소창에 붙여넣기 |
